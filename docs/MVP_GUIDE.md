# V3 使用与故障处理

以 README 为完整口径和配置入口。正式命令为 `python tracker.py --config tracker_config.json --output data`。

- `regions`：1至12个大写地区代码；自动去重。
- `categories_per_run`：每地区每轮1至4个类别，按UTC六小时时段确定轮转位置。
- `pool_limit`：50至5000，默认3000；不能小于仍在追踪的既有成员数（需显式调整追踪配置或等退池）。
- `tracking_days`：2至24天，默认14；按最后发现时间退池，不按发布时间退池。
- `search_budget`：每轮搜索尝试上限1至24，默认12，地区数×每轮类别数不可超过它。
- `request_budget`：所有端点每轮尝试总上限10至500，默认100。

若没有合格榜：先看 JSON 的 `excluded` 和 Markdown 缺测统计；不要用累计播放量补榜。当前快照相对 T 超15分钟时，该视频被排除；采集过慢应降低池容量或提高运行环境性能。调度偏移过大时等待后续正常窗口，不放宽成18至30小时。

若 API、恢复、配额、损坏数据、存储体积上限导致失败：本轮不会发布部分排名；上一个成功 Release 资产保留。检查 Actions 失败步骤、Cloud Console 实际桶配额及 Release 访问权限；不要记录 API 响应体或密钥。请求默认不重试，避免失败风暴。再次运行先恢复持久快照与配额账本。

Release 压缩包限20MB、解压总大小限200MB；仅恢复 history/reports 下的 .json/.md/.csv，拒绝路径逃逸。若触及上限，本轮持久化失败，旧资产不会先删除；需要评估池容量及历史存储方案，不把 artifact 当长久存储。若 Release 被删除将冷启动，至少24小时重新建基线；V2 不能替代 V3 精确历史。

报告 JSON 为完整机器可读素材（包括所有排除项）；CSV 为前10条，来源是JSON字符串；Markdown 为中文编辑素材。视频标题按不可信文本转义，CSV 对公式前缀加保护。时间戳统一UTC，调度说明同时提供北京时间。
